# Security policy

## Supported code

Security fixes target the latest commit on `main`. This project is pre-1.0 and does not currently maintain older release branches.

## Report a vulnerability

Use GitHub private vulnerability reporting from the repository's **Security** tab. Include the affected version or commit, the impact, and the smallest reproduction you can provide without exposing mailbox data or credentials.

If private reporting is unavailable, open a short public issue asking for a private contact route. Do not include exploit details, tokens, email addresses, message contents, hostnames, or provider credentials in that issue.

No response or remediation SLA is currently published.

## Testing boundaries

Test only accounts and infrastructure you own or are authorized to use. A security report does not authorize access to third-party mailboxes, endpoints, or MCP clients.
